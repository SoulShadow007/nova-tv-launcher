# Nova TV Launcher

Быстрый лаунчер для Android TV-приставок с управлением только с пульта (D-pad).

![CI](https://github.com/SoulShadow007/nova-tv-launcher/actions/workflows/build.yml/badge.svg)

## Возможности

- **Избранное** — панель любимых приложений на главном экране. При фокусе на приложении появляется панель предпросмотра: рекомендации, «продолжить просмотр», число зрителей, новинки.
- **Все приложения** — сетка установленных приложений; кнопка MENU (или долгое нажатие OK) добавляет/убирает приложение из избранного.
- **Системные показатели** — загрузка RAM, температура чипа, реальная скорость сети и статус VPN (чип VPN открывает системные настройки VPN).
- **Погода и часы** — живая погода через Open-Meteo (без API-ключа), кэш работает офлайн; город выбирается в настройках.
- **Четыре темы** — «Нова» (тёмная), «Аврора» (фиолетовая), «Янтарь» (ретро-CRT), «Кристалл» (светлая).
- **Обои** — статичное изображение или видео (зацикленное, без звука) из встроенного файлового менеджера.
- **Файловый менеджер** — навигация по хранилищу, открытие изображений/видео системными плеерами.
- **Анимации переходов** — три стиля на выбор: плавное, сдвиг, масштаб.

## Сборка

CI (GitHub Actions) собирает debug-APK при каждом push и публикует его в
[Releases](https://github.com/SoulShadow007/nova-tv-launcher/releases) (тег `continuous`),
а также как артефакт сборки.

Локально (требуется JDK 17+):

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

## Управление

| Кнопка пульта | Действие |
| --- | --- |
| Стрелки | навигация по избранному и нижней панели |
| OK | открыть приложение / выбрать пункт |
| MENU или долгий OK | добавить/убрать из избранного |
| BACK | закрыть диалог |

## Технологии

Kotlin, AndroidX (AppCompat, RecyclerView, Lifecycle), Coroutines, минимум зависимостей.
minSdk 21 (Android 5.0+), targetSdk 34, landscape, регистрируется как HOME-приложение.

## Структура

```
app/src/main/java/com/novatv/launcher/
├── MainActivity.kt        — главный экран
├── apps/                  — загрузка приложений, избранное, «Все приложения»
├── system/                — RAM, температура, скорость сети, VPN
├── weather/               — Open-Meteo + кэш
├── themes/                — 4 темы оформления
├── wallpaper/             — статичные и видеообои
├── files/                 — файловый менеджер
├── settings/              — настройки и выбор обоев
└── ui/                    — анимации, предпросмотр, утилиты
```
